# Technology Stack

- Frontend: React + Vite + TypeScript
- UI: shadcn/ui + Tailwind CSS
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Architecture: Modular monolith
- API: REST API
- Validation: Zod
- Authentication: Secure session or JWT-based authentication
- Testing: Vitest + Supertest
- Language support: Burmese and English

Use stable, compatible package versions. Keep frontend and backend in separate directories within one repository.
