# Project Goal

Build a Myanmar-first Student Management System for private schools as a multi-tenant SaaS platform.

The system should simplify school administration by managing students, guardians, admissions, classes, subjects, teachers, attendance, examinations, grades, fees, payments, reports, and parent/student communication.

Support Burmese and English, Myanmar Unicode, MMK currency, local academic calendars, and payment workflows involving cash, bank transfers, KBZPay, WavePay, and AYA Pay.

Each school must manage its own data securely, with role-based permissions and strict school-level data isolation.

The platform should be mobile-responsive, easy to use, suitable for Myanmar school workflows, and reliable in low-bandwidth environments.

The main objective is to reduce administrative workload, improve data accuracy, simplify academic and financial management, and strengthen communication between schools and parents.
