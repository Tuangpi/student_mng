# Implementation Plan

## Phase 1: Foundation
- Initialize React, Vite, TypeScript, shadcn/ui, Express, and Prisma.
- Configure PostgreSQL, environment variables, validation, logging, and error handling.
- Implement authentication, roles, school setup, and tenant isolation.

## Phase 2: School Operations
- Academic years, terms, classes, and subjects.
- Student admissions, profiles, guardians, and enrollments.
- Teacher profiles and assignments.

## Phase 3: Academic Management
- Attendance.
- Examinations and grading.
- Report cards and academic reports.

## Phase 4: Financial Management
- Fee structures and invoices.
- Manual payment recording.
- Outstanding balances and financial reports.

## Phase 5: Portals and Communication
- Parent and student portals.
- Announcements and notifications.
- Burmese/English interface and printable documents.

## Phase 6: Production Readiness
- Automated tests and tenant-isolation tests.
- Security review and performance improvements.
- Backups, deployment, monitoring, and documentation.

Complete and test each phase before moving to the next.
